# Security scope

Offline synthetic learning model only. Admitted Unicode values can include controls, default ignorables, unassigned/private-use scalars and empty strings. Their admission is not a production identifier recommendation. Do not feed passwords, real usernames/accounts/domains, employer/client or other private data to this lab. Output is reversible text/code points, not redaction.

Exact, NFC and ordered NFKC/default full casefold/NFKC equality does not establish visual identity, authenticity, authorization or spoof resistance. This is not official toNFKC_Casefold, UTS39 conformance, an identifier registry or an authentication service. No IDNA/email/filesystem/network transformations or remote lookups occur. File paths specify local evidence I/O only.

Whole-envelope exact-type/schema validation precedes unsupported profile/runtime outcomes. JSON bytes/nesting/records/string scalars and transformation expansion are bounded. Unsupported runtime/profile and invalid/over-limit data have distinct statuses; no partial grouping is emitted after analysis failure. ASCII JSON and code points preserve control/format evidence without raw terminal effects. UTF-8/scalar and batch limits constrain computation, not wall-clock/RSS isolation or zero temporary allocation.

Regular-file metadata checks detect observed changes but do not defeat hostile filesystem races. Exclusive output creation protects existing/input files; output may be partial if later writing/flush/close fails. Stdout is not atomic. A complete analysis delivered unsuccessfully returns error, and its partial output must not be used. Error messages use bounded fixed diagnostics and do not echo filenames, input labels or OS exception text.

Runtime guard admits CPython 3.13.x/UCD 15.1.0; locally tested only Windows/CPython 3.13.7. Independent selected fixtures and source-integrity hashes do not establish full Unicode conformity, provenance authentication, cross-version equality or visual behavior. No third-party runtime dependency; installed scanner dependencies are development-only.

Local repository has no remote; branch is codex/unicode-policy. Prepared CI targets a future main default branch: normal/optimized tests and Bandit on push/PR/manual, CodeQL additionally weekly, SHA-pinned actions/minimum permissions/persist-credentials false. Action commit identities were fetched from official repositories during this task. Hosted CodeQL/Bandit execution, repository visibility/protections/reviews, secret scanning/push protection eligibility and alerts are unavailable until Jake authorizes repository publication/configuration. Dependabot configuration is prepared for development dependencies/actions. Exact scanner pins are not hash-locked wheels or an advisory audit. No protections were weakened and no GitHub settings changed.
